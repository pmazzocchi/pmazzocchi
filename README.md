# Hi, I'm Paolo 👋

## What I work on

- **Crypto custody & operations** – cold storage design, multisig and timelocked scripts, PSBT-based signing workflows
- **Regulation** – MiCAR authorization and ongoing compliance for a licensed CASP
- **Quantitative finance** – derivatives pricing, basis and carry strategies, with a long-standing interest in [QuantLib](https://github.com/lballabio/QuantLib)
